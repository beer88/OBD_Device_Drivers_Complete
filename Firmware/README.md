# Firmware

This folder contains the ESP32 firmware used to operate the OBD device.

## Features

- CAN bus data acquisition
- OBD-II PID reading
- GPS location acquisition
- GSM communication
- Telemetry transmission

## Development Environment

Recommended tools:

- Arduino IDE
- PlatformIO
- ESP-IDF (optional)

## Firmware Modules

- CAN driver
- GPS parser
- GSM communication
- OBD protocol handler
